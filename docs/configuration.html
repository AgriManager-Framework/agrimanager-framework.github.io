Configuration

Most config comes from VeRL — here are the keys you set, plus the ones AgriManager adds.

AgriManager is configured with YAML files plus Hydra command-line overrides. Every run is defined by a config; the command line only adjusts it. There are no hidden argparse flags.

Config layers#

A training config is three layers, each overriding the one below:

  • VeRL base — ppo_trainer (from the VeRL submodule): every RL and training default.
  • AgriManager defaults — agri_grpo (default) or agri_ppo: override some VeRL defaults and add the AgriManager-only keys.
  • CLI overrides — Hydra key=value on the command line: per-run tweaks.

So most keys you see are VeRL's — AgriManager only overrides a few and adds a few. Pick a config with --config-name, then override any field:

bash
bash entrypoints/train/train.sh \
  --config-name agri_grpo \
  actor_rollout_ref.model.path=Qwen/Qwen2.5-3B-Instruct \
  trainer.experiment_name=my_experiment \
  trainer.total_epochs=1

Environment keys (dataset config)#

Important

Anything that changes environment semantics is set in the dataset config (under env:) and baked into each parquet row, so the same split always reconstructs the same environment. To change the environment, edit the dataset config and rebuild. The one exception is the response format at evaluation: the frozen test suite is built in the no-think format, and the evaluator applies each checkpoint's own format with data.env_config_overrides and checks it with data.assert_env_config (see Evaluation).

Environment variables#

Provider API keys are read from the environment, only for the provider you use:

bash
export OPENAI_API_KEY="sk-..."          # OpenAI
export GEMINI_API_KEY="..."             # Google Gemini
export OPENROUTER_API_KEY="sk-or-..."   # OpenRouter

The default vLLM-offline path needs no key. Training and evaluation log to Weights & Biases; run wandb login once if you want logging. To keep runs local, pass trainer.logger='["console"]' to training, wandb.enabled=false to scripted-policy evaluation, or set WANDB_MODE=offline.
